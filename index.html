Översikt

            Så publicerar du på GitHub Pages
            
1. Skapa ett nytt GitHub-repo.
2. Lägg denna fil i roten och döp den till index.html.
3. Gå till Settings → Pages.
4. Välj Deploy from branch.
5. Välj main och /root.
6. Öppna den publicerade Pages-länken.
